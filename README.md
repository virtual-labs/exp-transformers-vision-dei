### About the Experiment 

This experiment provides an interactive exploration of **Transformers** in **Computer Vision**. It demonstrates how transformer architectures (Vision Transformers, Attention Mechanisms) are applied to image processing and visual recognition tasks, enabling students to understand the evolution from Convolutional Neural Networks to transformer-based vision models.
